# WeatherTrack 

A modern React app for tracking the weather.

## Features

- City search
- Current weather
- 5-day forecast
- Temperature charts
- Responsive design

## Technologies

- React.js
- Vite
- Axios
- Recharts
- OpenWeather API

## Installation

```bash
npm install
npm run dev
```

## API

OpenWeatherMap API
